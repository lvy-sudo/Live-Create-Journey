# Live · Create · Journey

纯前端个人网站：HTML + CSS + 原生 JavaScript，无框架、无构建步骤。支持多级右滑进入、页面内增删改、本地照片上传、浏览数据持久化和 PWA 安装。

## 一、最快打开方式

1. 双击项目根目录的 **`start-site.cmd`**。
2. 浏览器会自动打开 `http://127.0.0.1:4173/`。
3. 使用期间保留弹出的命令行窗口；关闭窗口即可停止本地服务器。

不要直接双击 `index.html` 来测试 PWA。`file://` 地址不属于安全上下文，浏览器不会安装 Service Worker，因此无法安装到桌面。

如果 `start-site.cmd` 提示找不到 Node.js，请先安装 Node.js LTS，然后重新双击。也可以使用任意静态文件服务器托管本目录。

## 二、页面内编辑

首页三个主分类固定，不可新增或删除。进入分类后，所有二级方框都可以：

- 点击方框：向右滑入下一级详情页。
- 点击“编辑”：修改标题、简介和正文。
- 点击“删除”：删除后可通过右下角提示中的“撤销”恢复。
- 点击“添加项目 / 添加技能 / 添加兴趣”：新增二级方框。
- 在详情页点击“添加链接”：新增可点击的外部链接，并可单独删除。
- 使用 `Esc` 或“← 返回”：按相反方向滑回上一级。

### 摄影

进入“兴趣爱好 → 摄影”后：

1. 点击“＋ 添加照片”。
2. 浏览器会自动打开文件资源管理器。
3. 可多选本地图片，确认后填写作品集名称和说明。
4. 保存后生成作品集方框；点击作品集可继续滑入照片详情。
5. 在作品集详情中还可以继续添加或删除照片。

图片文件保存在当前浏览器的 IndexedDB 中，不会上传到互联网。

### 旅行

进入“兴趣爱好 → 旅行”后：

1. 点击“＋ 新增游记”创建游记方框。
2. 点击游记进入游记详情。
3. 点击“＋ 添加文字记录”记录日期和文字。
4. 点击“＋ 添加照片”会直接打开文件资源管理器；选择照片后可补充日期、配文和照片说明。
5. 每条记录还可以继续添加照片、编辑文字或删除。

### 数据保存位置

- 文字、链接、项目和游记配置：浏览器 `localStorage`，键名为 `lcj-site-data-v2`。
- 上传的照片：浏览器 IndexedDB，数据库名为 `lcj-photo-library`。
- 所有默认内容集中在 **`src/data.js`**；页面 HTML 中没有写死二级内容结构。
- 页面内修改只保存在当前浏览器，不会自动同步到其他电脑或其他浏览器。
- 清除浏览器“网站数据”会同时清除页面内新增内容和上传照片，请勿随意清理。

如需恢复默认示例内容：按 `F12` 打开开发者工具，在“应用程序 / Application”中删除 Local Storage 里的 `lcj-site-data-v2` 和 IndexedDB 里的 `lcj-photo-library`，然后刷新页面。

## 三、安装到桌面（Windows）

### Microsoft Edge

1. 双击 `start-site.cmd`，等待浏览器打开 `http://127.0.0.1:4173/`。
2. 等待页面完全加载几秒钟，让 Service Worker 完成首次缓存。
3. 点击首页左下角的“安装到桌面”按钮；如果没有看到按钮，请点击地址栏右侧的“安装”图标。
4. 也可以打开 Edge 右上角菜单 → “应用” → “将此站点作为应用安装”。
5. 在安装窗口中将名称保留为 `Live · Create · Journey`，点击“安装”。
6. 安装完成后，桌面和开始菜单会出现 LCJ 图标，双击即可像普通应用一样打开。

### Google Chrome

1. 双击 `start-site.cmd` 打开本地网站。
2. 点击地址栏右侧的安装图标，或打开右上角菜单 → “安装 Live · Create · Journey”。
3. 点击“安装”。桌面会生成应用快捷方式。

### 安装后如何离线打开

首次成功打开并安装后，Service Worker 会缓存网站外壳。之后即使关闭本地服务器，也可以从桌面图标打开已经缓存的页面和内容。

如果要修改代码或新增本地图片，请重新双击 `start-site.cmd` 启动服务器并在线刷新一次，让缓存更新。

### 卸载

- Windows：设置 → 应用 → 已安装的应用 → 找到 `Live · Create · Journey` → 卸载。
- 或右键桌面快捷方式选择删除；若需要彻底移除，可在浏览器的“应用”管理页面中卸载。

### macOS / 手机

- macOS Chrome / Edge：打开本地网站后，在浏览器菜单中选择“安装”或“添加到程序坞”。
- iPhone / iPad Safari：点击分享按钮 → “添加到主屏幕”。
- Android Chrome：右上角菜单 → “安装应用”或“添加到主屏幕”。

PWA 的一键安装提示只会在 `http://localhost`、`http://127.0.0.1` 或 HTTPS 下出现。

### 更新代码或 Logo 后，已安装应用如何同步

- 桌面应用本质上是同一网址的独立窗口，不会复制一份旧网站。启动本地服务器后重新打开应用，代码和默认内容会加载最新版本。
- Service Worker 使用网络优先策略：在线时获取最新文件，离线时回退到上一版缓存。
- 页面内编辑的内容保存在当前浏览器的 localStorage 中。即使代码更新，只要仍是同一个 `http://127.0.0.1:4173` 地址，已有内容会继续保留。
- 如果修改了 `src/data.js` 的默认内容，但浏览器里已有 `lcj-site-data-v2`，页面仍会优先显示浏览器中保存的版本。需要恢复默认配置时，删除该 Local Storage 项后刷新。
- 桌面快捷方式图标可能被 Windows 或浏览器缓存。若新 Logo 没有立即出现，先彻底关闭应用并重新启动；仍然不更新时，卸载后重新安装一次即可。

当前圆形太空 Logo 源文件为 `assets/icons/logo-circle.svg`，PWA 使用 `icon-circle-192.png` 和 `icon-circle-512.png`。

## 四、目录结构

```text
LCJ/
├── index.html                 # 页面外壳
├── manifest.webmanifest       # PWA 清单
├── service-worker.js          # 离线缓存
├── server.js                  # 零依赖本地服务器
├── start-site.cmd             # Windows 双击启动入口
├── src/
│   ├── data.js                # 全站默认内容配置
│   ├── main.js                # 多级视图、编辑、存储与交互
│   └── styles.css             # 样式和动画
├── assets/
│   ├── icons/                 # PWA 图标
│   └── images/                # 默认背景与示例图片
└── README.md
```

## 五、动画实现说明

- 普通浏览器：使用 `transform: translateX(...)` + `transition`，时长 `500ms`，缓动 `cubic-bezier(0.4, 0, 0.2, 1)`。
- 支持 View Transitions API 的浏览器：自动使用同方向的自定义视图过渡。
- 前进：当前页向左退出，新页从右侧进入；返回：当前页向右退出，上一页从左侧进入。
- 系统启用“减少动态效果”时，动画缩短到几乎瞬间完成。

## 六、开发检查

无需安装依赖。可在项目目录运行：

```powershell
node --check src\data.js
node --check src\main.js
node --check service-worker.js
node --check server.js
```

## 七、本地内容与部署提醒

这是纯前端站点，页面内编辑结果保存在访问者自己的浏览器中，不会写回 `src/data.js`，也不会跨设备同步。如果未来部署到公开服务器，默认内容会来自 `src/data.js`；每个访问者在自己的浏览器中进行的修改只对他们自己可见。
